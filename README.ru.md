# Stepwise

[English](README.md) | Русский

Stepwise: Telegram-бот, который проводит пользователя через короткую последовательность шагов и позволяет скачать PDF-чеклист. Интерфейс бота, содержание гайда и сообщения написаны на английском языке.

Пример гайда охватывает три этапа небольшого проекта: постановку цели, планирование работы и проверку результата.

## Возможности

- **Главное меню:** команда `/start` показывает четыре действия в виде кнопок Telegram.
- **Гайд из трёх шагов:** Start Guide открывает первый шаг. Next и Back переключают шаги; Back на первом шаге или Main Menu возвращают в меню.
- **Завершение гайда:** Next на последнем шаге показывает сообщение о завершении. Гайд можно пройти заново с начала.
- **Независимый прогресс:** у каждого пользователя свой прогресс в каждом чате. Прогресс хранится в памяти и сбрасывается после перезапуска бота.
- **Контакт администратора:** Contact Admin показывает настроенную ссылку на контакт в Telegram. Если контакт не настроен, появляется явно обозначенный демо-режим с кнопкой Open Demo Link, ведущей на `https://example.com`.
- **Скачивание PDF:** Download Checklist отправляет чеклист проекта. Если файл недоступен, бот сообщает об этом.
- **Помощь:** команда `/help` и кнопка Help объясняют работу меню, навигацию по гайду, скачивание PDF и контакт администратора. Просмотр помощи сохраняет текущий шаг.
- **Подсказки:** неизвестный текст, команды и неподдерживаемые медиа вызывают подсказку с текущими кнопками навигации, не меняя прогресс гайда.

## Меню

| Кнопка | Действие |
| --- | --- |
| Start Guide | Открыть гайд из трёх шагов. |
| Download Checklist | Получить чеклист проекта в формате PDF. |
| Contact Admin | Показать настроенный контакт администратора или демонстрационную кнопку со ссылкой на пример сайта. |
| Help | Показать инструкции, сохранив текущий шаг гайда. |

## Команды

| Команда | Действие |
| --- | --- |
| `/start` | Вернуться в главное меню и сбросить прогресс гайда в текущем чате. |
| `/help` | Показать инструкции без сброса прогресса гайда. |

Help, Download Checklist, Contact Admin и ответы на неизвестные сообщения сохраняют текущий шаг и кнопки Next, Back и Main Menu во время прохождения гайда. Вне гайда остаётся доступным главное меню. Main Menu или Back на первом шаге завершают прохождение; `/start` сбрасывает его; Start Guide начинает гайд заново с первого шага. Next на последнем шаге завершает гайд.

## Технологии

- Python 3.10 или новее
- python-telegram-bot 22.8 для работы с сообщениями и обработчиками Telegram
- python-dotenv для локальной конфигурации

Версии зависимостей зафиксированы в `requirements.txt`. Бот получает обновления методом polling: периодически запрашивает их у Telegram.

## Установка и запуск

Создайте `.env` на основе `.env.example` и укажите токен своего Telegram-бота в `BOT_TOKEN`. При необходимости задайте `ADMIN_CONTACT_URL`, указав публичную ссылку на имя пользователя Telegram в формате `https://t.me/<username>`. Если оставить значение пустым, бот покажет демо-контакт со ссылкой на `https://example.com`. После изменения конфигурации перезапустите бота.

### Windows

Откройте PowerShell в папке проекта, создайте виртуальное окружение и установите зависимости:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Запустите бота:

```powershell
.\.venv\Scripts\python.exe bot.py
```

### Linux

Нужен Python 3.10+ с поддержкой `venv`. В Ubuntu и Debian эту поддержку предоставляет пакет `python3-venv`.

В папке проекта создайте виртуальное окружение и установите зависимости:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

Запустите бота:

```bash
.venv/bin/python bot.py
```

Бот работает в текущем терминале. Для остановки нажмите `Ctrl+C`.

## Изменение содержимого

Измените `GUIDE_STEPS` в `content.py`, чтобы заменить пример гайда. Остальные английские сообщения и подписи кнопок находятся в том же файле. Подписи кнопок, используемые для выбора обработчика, должны соответствовать действиям в `bot.py`.

Чтобы заменить скачиваемый документ, обновите `files/checklist.pdf`, сохранив имя файла.
